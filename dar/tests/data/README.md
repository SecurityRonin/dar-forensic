# tests/data — DAR Corpus

Synthetic corpus generated by a Python script using only the DAR format
specification, independent from the Rust parser (doer-checker principle).

## Files

| File | Size | Description |
|------|------|-------------|
| `test.dar` | 4.7 KB | DAR archive with three entries |

## Archive Contents

| Path | Size | Content |
|------|------|---------|
| `boot/mbr.bin` | 512 B | `bytes(range(256))` repeated twice |
| `etc/hostname` | 12 B | `b"corpus-host\n"` |
| `data/pattern` | 4096 B | `bytes(range(256))` repeated 16 times |

## Regenerating

```bash
python3 - <<'EOF'
import struct, zlib

def encode_entry(path, data):
    name = path.encode()
    crc = zlib.crc32(data) & 0xFFFFFFFF
    return (
        struct.pack(">H", len(name)) + name +
        struct.pack(">Q", len(data)) +
        data +
        struct.pack(">I", crc)
    )

entries = [
    ("boot/mbr.bin", bytes(range(256)) * 2),
    ("etc/hostname",  b"corpus-host\n"),
    ("data/pattern",  bytes(range(256)) * 16),
]

body = b""
catalog_entries = []
for path, data in entries:
    offset = len(body)
    chunk = encode_entry(path, data)
    body += chunk
    catalog_entries.append((path.encode(), offset))

# CATL catalog
catl = b"CATL"
catl += struct.pack(">I", len(catalog_entries))
for name, offset in catalog_entries:
    catl += struct.pack(">H", len(name)) + name + struct.pack(">Q", offset)

magic = b"DAR\x00"
version = struct.pack(">I", 1)
count = struct.pack(">I", len(entries))

with open("test.dar", "wb") as f:
    f.write(magic + version + count + body + catl)
EOF
```

> **Note**: the exact byte layout depends on your DAR format version. Verify
> with `shasum -a 256 test.dar` against a known-good checksum if regenerating.
